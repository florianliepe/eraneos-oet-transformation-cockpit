# ZM-PROD-11–17 pilot release

This release delivers workspace governance, portfolio control, project workbench, governed n8n agent operations, executive reporting, accessible Eraneos design and the operational-quality baseline. Every agent path remains proposal-first and requires accountable review before canonical publication.

The live target is `https://florianliepe.github.io/eraneos-oet-transformation-cockpit/`. Release evidence consists of the merged Git commit, both green GitHub Actions workflows, the deployed Pages artifact and the versioned n8n release manifest.

Operational additions include privacy-safe correlation errors, stale-binding diagnostics, analytics disabled by default, asset budgets, dependency/security and cross-browser gates, and reproducible non-destructive recovery evidence.

Azure production activation, Entra External ID, managed PostgreSQL, Teams and SharePoint remain explicitly excluded. Browser-local identity and persistence are not production security.
