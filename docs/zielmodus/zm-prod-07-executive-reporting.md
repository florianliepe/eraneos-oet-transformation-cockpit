# ZM-PROD-07 — Executive reporting

## Objective

Produce configurable, evidence-linked executive reporting with accountable review and immutable publication history.

## Work package

1. Add configurable SteerCo modules for delivery, risks, decisions, benefits, finances and scenarios.
2. Generate evidence-linked narrative proposals without automatic approval.
3. Add reporting-period comparison, trends and material-change explanations.
4. Add reviewer overrides with rationale and audit lineage.
5. Publish immutable read-only report versions with revocation support.
6. Add PDF and PowerPoint export using the approved Eraneos visual system.
7. Verify exports for content, layout, accessibility and source lineage.

## Acceptance gate

- Every material narrative claim links to evidence or is explicitly marked as judgement.
- Reports cannot publish without accountable review.
- Published versions remain immutable and reproducible.
- PDF and PowerPoint outputs pass automated and visual verification.

## Deployment outcome

Deploy reporting workbenches and verified export artifacts before smarter orchestration.
